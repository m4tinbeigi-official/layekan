# لایه‌کَن (Layekan)

کلیک روی هر ناحیه‌ی هایلایت‌شده یا خط‌کشی‌شده‌ی یک تصویر، و بازیابی خودکار محتوای زیر آن.

یک ابزار کاملاً سمت کاربر (Client-Side): هیچ تصویری آپلود نمی‌شود و همه‌ی پردازش‌ها در مرورگر انجام می‌شود.

## چرا کار می‌کند؟

ابزارهای هایلایت و خط‌کشی (مثل Markup گوشی) معمولاً پیکسل‌های زیر خود را حذف نمی‌کنند؛ فقط روی آنها ترکیب می‌شوند:

```
observed = a × marker + (1 − a) × hidden
```

لایه‌کَن این ترکیب را وارونه می‌کند:

```
hidden = (observed − a × marker) ÷ (1 − a)
```

روی هر پیکسلی که کلیک می‌کنی:

1. رنگ جوهر از ناحیه‌ی اطراف نقطه‌ی کلیک برداشته می‌شود.
2. شفافیت جوهر (α) به‌صورت خودکار از روشن‌ترین پیکسل‌های هم‌رنگ تخمین زده می‌شود (فرض: کاغذ زیر جوهر روشن است). می‌توانی دستی هم تنظیم کنی.
3. روی پیکسل‌های بازیابی‌شده یک کشش خودکار کنتراست (صدک ۲ تا ۹۸) اجرا می‌شود؛ معادلِ خودکارشده‌ی همان ترفند Curves روی کانال Value در GIMP.

برای چند رنگ مختلف (مثلاً خط قرمز و هایلایت زرد در یک تصویر) کافی است روی هر کدام جداگانه کلیک کنی.

## استفاده

1. تصویر را رها کن یا انتخاب کن.
2. روی ناحیه‌ی مخدوش‌شده کلیک کن. همین.
3. اگر نتیجه کامل نیست، اسلایدرهای «شفافیت جوهر»، «تلورانس رنگ» و «شدت بازیابی» را تنظیم کن.
4. خروجی PNG را دانلود کن.

با کیبورد هم می‌شود: `Tab` تا بوم، کلیدهای جهت‌نما برای حرکت نشانه‌گذار و `Enter` برای برداشتن رنگ.

## انتشار روی GitHub Pages

1. یک مخزن جدید در GitHub بساز.
2. `index.html` را در ریشه‌ی مخزن قرار بده و کامیت کن.
3. از منوی **Settings > Pages**، بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کن، شاخه‌ی `main` و پوشه‌ی `/ (root)` را بزن و ذخیره کن.
4. بعد از یک تا دو دقیقه، آدرس `https://<username>.github.io/<repo>/` فعال می‌شود.

وابستگی یا Build لازم نیست؛ یک فایل HTML استاتیک است.

## محدودیت‌ها

- اگر پوشانه‌گذاری با مستطیل **کاملاً مات سیاه** (α = ۱۰۰٪) انجام شده باشد، چیزی برای بازیابی باقی نمی‌ماند و هیچ ابزاری نمی‌تواند برگرداند.
- اگر تصویر بعد از خط‌کشی دوباره ذخیره یا فشرده شده باشد، باز هم اطلاعات ترکیب‌شده حفظ می‌شود و بازیابی ممکن است؛ اما کیفیت به فشرده‌سازی بستگی دارد.
- برای پس‌زمینه‌های تیره، تخمین خودکار α ممکن است خطا داشته باشد؛ در این حالت اسلایدر شفافیت را دستی تنظیم کن.

## پوشانه‌گذاری امن (سمت مقابل)

- از هایلایتر و ماژیک نیمه‌شفاف استفاده نکن؛ یک مستطیل کاملاً مات سیاه بکش.
- قبل از خط‌کشی از سند اسکرین‌شات بگیر و روی اسکرین‌شات کار کن تا لایه‌ی اصلی و متادیتا از بین برود.
- وقتی اطلاعات حیاتی است، به‌جای پوشاندن، همان قسمت را برش بزن (Crop) و اسکرین‌شات نهایی را دوباره ذخیره کن.
